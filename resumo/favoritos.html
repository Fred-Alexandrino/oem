Favorito "Resumo WhatsApp"

1. Instalar

  1. Mostre a barra de favoritos: Ctrl+Shift+B.
  2. Arraste os dois botões abaixo para a barra de favoritos:

    📝 Resumo WhatsApp   ⚙ Editar grupos
    Resumo WhatsApp lê os grupos e gera o resumo. Editar grupos só abre a lista para marcar/desmarcar grupos e não lê nada.

Se não conseguir arrastar: clique em "Copiar código", crie um favorito novo (botão direito na barra > Adicionar página), deixe o nome "Resumo WhatsApp" e cole o código no campo URL.

2. Instalar a extensão "Ponte Claude" (para enviar ao Claude sozinho)

Descompacte o ponte-claude.zip, abra chrome://extensions, ligue o Modo do desenvolvedor e clique em Carregar sem compactação escolhendo a pasta. Depois recarregue o WhatsApp Web (F5). Com ela, ao terminar a leitura o favorito abre o Claude com o texto já colado e você só aperta Enter. Sem a extensão, o favorito copia o texto e abre o Claude para você colar (Ctrl+V).

Opcional (modo Gemini): se preferir o resumo pela página do Gemini, cole aqui o endereço da página de resumo e arraste os botões de novo. Em branco = Claude.

3. Usar

  1. Abra o web.whatsapp.com (com a lista de conversas visível).
  2. Clique no favorito. Na primeira vez, marque os grupos e diga se cada um é Cliente ou Equipe. A escolha fica salva.
  3. Espere: ele abre cada grupo, lê de ontem 00:00 até agora e junta tudo. Não troque de aba enquanto lê.
  4. Nas próximas vezes é só clicar. Para mudar os grupos, use "Editar grupos".
